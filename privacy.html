Какие данные обрабатываются

Сайт может обрабатывать следующие категории данных:

  • имя;
  • телефон;
  • email;
  • комментарий из формы заявки;
  • IP-адрес;
  • user-agent;
  • технические cookies;
  • данные о действиях пользователя на сайте;
  • данные, необходимые для работы Яндекс.Карт.

Цели обработки

Персональные и технические данные могут обрабатываться в следующих целях:

  • обработка заявок пользователей;
  • обратная связь;
  • подбор коммерческих помещений;
  • демонстрация объектов на карте;
  • корректная работа сайта;
  • улучшение пользовательского опыта.

Правовые основания обработки

Обработка данных осуществляется на основании согласия пользователя, выраженного при направлении заявки через форму сайта, а также в случаях, когда обработка необходима для функционирования сайта, обратной связи и исполнения запросов пользователя.

Cookies и технические данные

Сайт использует технические cookies и локальное хранилище браузера для корректной работы интерфейса, сохранения согласия с cookie-уведомлением, избранных помещений и пользовательских настроек. Отключение cookies может ограничить работу отдельных функций сайта.

Использование Яндекс.Карт

На сайте может использоваться сервис Яндекс.Карты для демонстрации расположения объектов. При загрузке карты сервис может получать технические данные, необходимые для отображения карты и построения маршрутов, в соответствии с правилами соответствующего сервиса.

Передача данных третьим лицам

Оператор не продает персональные данные пользователей. Данные могут передаваться третьим лицам только когда это необходимо для обработки заявки, связи с пользователем, работы сайта, использования подключенных сервисов или исполнения требований законодательства.

Сроки хранения данных

Данные хранятся не дольше, чем это необходимо для целей обработки, ответа на обращение пользователя, сопровождения коммерческой коммуникации и соблюдения применимых требований законодательства. Пользователь может направить запрос на прекращение обработки или удаление данных.

Права пользователя

Пользователь вправе получать сведения об обработке своих персональных данных, требовать уточнения, блокирования или удаления данных, а также принимать иные меры, предусмотренные применимым законодательством о персональных данных.

Отзыв согласия

Пользователь может отозвать согласие на обработку персональных данных, направив обращение оператору по электронной почте. После получения обращения оператор прекращает обработку данных, если отсутствуют иные законные основания для продолжения обработки.
