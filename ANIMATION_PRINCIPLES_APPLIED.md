# Применение 6 принципов анимации

В проект добавлена единая motion-система без дополнительных зависимостей: только CSS keyframes, transition tokens и небольшой делегированный JS для микровзаимодействий. Все эффекты работают на desktop, tablet и mobile и отключаются через `prefers-reduced-motion`.

## 1. Сжатие и растяжение
- Добавлены `abPressSquash` и `abFavoriteBeat`.
- Применено к кнопкам, избранному, карточкам, фильтрам, чипам, маркерам карты и ползункам.
- Эффект небольшой, чтобы сохранить строгий и премиальный стиль сайта.

## 2. Подготовка
- Перед кликом/активацией элементы дают короткий preparatory-импульс.
- Hover/focus у CTA и карточек слегка приподнимает элемент и готовит пользователя к действию.
- Drawer, modal и мобильное меню открываются через более выразительный вход.

## 3. Сценичность
- Scroll reveal стал более направленным: важные секции проявляются с понятной иерархией.
- Hero, CTA, карта, карточки лотов и блоки характеристик получают staged-появление.
- Заголовки и линии акцента теперь визуально фокусируют внимание.

## 4. Последовательность и от позы к позе
- Добавлен stagger-порядок для сеток карточек, объектов, лотов, характеристик и дорожных карт.
- JS задаёт `--motion-index`, CSS использует его для последовательного входа элементов.
- Появления построены через ключевые позы: старт → лёгкий overshoot → финальная позиция.

## 5. Сквозное движение / захлёст
- Медиа-слои, hero image, карта, планировки и визуальные блоки получили мягкое follow-through движение.
- В modal/drawer и карточках движение заканчивается не резко, а с лёгким доводом.
- Изображения внутри карточек движутся немного дольше, чем сами карточки.

## 6. Замедление начала и конца
- Обновлены easing tokens: `--ease-out`, `--ease-in`, `--ease-in-out`, `--ease-follow`, `--ease-anticipate`.
- Убрана роботизированность: интерфейс ускоряется и замедляется естественно.
- Page transition, modal, cards, buttons, scroll reveal и mobile menu используют единые кривые.

## Затронутые файлы
- `style.css` — новая motion-система, keyframes, responsive motion, reduced-motion.
- `script.js` — инициализация принципиальной motion-системы, delegated press animations, motion-index для stagger.
- `ANIMATION_PRINCIPLES_APPLIED.md` — описание внедрения.

## Проверки
- `node -c script.js`
- `node -c data.js`
- HTML parser для основных страниц
- CSS parse через `tinycss2`

## Важно
Новые анимации не добавляют тяжёлых библиотек, не меняют бизнес-логику, не ломают роутинг и учитывают `prefers-reduced-motion`.
