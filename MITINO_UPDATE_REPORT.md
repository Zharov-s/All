# Обновление страницы Митино

## Что изменено

- Страница `mitino.html` теперь раскрывается как полноценная объектная страница в общем стиле сайта ABCENTRUM.
- В `script.js` добавлен отдельный сценарий `id === "mitino"`, аналогичный глубокой странице Некрасовки, но с логикой Митино.
- Контент собран из загруженных материалов по промтехнопарку Митино:
  - бутик-промтехнопарк класса A+;
  - адрес: Москва, Барышиха 37А;
  - общая площадь: 11 776,20 м²;
  - электрическая мощность: 1,5 МВт;
  - парковка: 70 м/м;
  - ввод: III квартал 2026 года;
  - 7 физических арендных лотов;
  - производственно-офисный контур 5 106,23 м² как сценарий объединения без дублирования лотов.
- Карта на странице Митино подтянута через Яндекс.Карты с точной отметкой: `55.849145, 37.340891`.
- Добавлены секции: о проекте, технические характеристики, инфраструктура, локация, ход строительства, коммерческие условия, лоты.
- Сценарий покупки для Митино не добавлен, так как объект работает только в аренде.

## Логика без дублей

- В каталоге остаются только 7 физических лотов `B37A-01` — `B37A-07`.
- Производственно-офисный контур 5 106,23 м² показан на странице как сценарий объединения существующих площадей, но не добавлен в `data.lots`, чтобы не раздуть каталог и не создать дубль площади.
- Для B37A-01/B37A-02 уточнены форматы по загруженному Митино-контенту: showroom 385,12 м² и кафе/ресторан 425,30 м².
