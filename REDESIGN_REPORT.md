# ABCENTRUM — отчет по обновлению

## Что изменено

- Добавлен новый раздел `Карта объектов` на главной странице.
- На карте размещены три отметки объектов ABCENTRUM:
  - Митино — `55.849145, 37.340891`;
  - Промтехнопарк «Некрасовка» — `55.676544, 37.930757`;
  - Медицинский центр «Грекова» — `55.888667, 37.661722`.
- Для каждого объекта добавлена кнопка `Проложить маршрут`, которая открывает Google Maps Directions.
- Кнопка маршрута добавлена также в карточки объектов и hero-блоки объектовых страниц.
- Палитра сайта скорректирована под загруженные файлы проекта: используются базовые цвета `#0f1a2a`, `#080a0f`, `#f3f5f7`, `#ffffff`.
- Закругления элементов уменьшены примерно на 80%: вместо овальных pill-форм используются более строгие radius-токены `3px / 4px / 6px / 8px`.
- Сохранена текущая логика каталога, фильтров, избранного, модальных окон, mailto-заявок и страниц объектов.

## Затронутые файлы

- `index.html`
- `script.js`
- `style.css`
- `REDESIGN_REPORT.md`

## Зависимости

Новые зависимости не добавлялись. Карта реализована без тяжелых библиотек: базовая карта загружается через OpenStreetMap iframe, а отметки и CTA отрисовываются локальным HTML/CSS/JS.

## Проверки

Выполнены проверки:

```bash
node -c script.js
python3 HTMLParser для index.html, lots.html, mitino.html, nekrasovka.html, grekova.html
python3 tinycss2 parse для style.css
zip -T abcentrum-redesign-map-update.zip
```

## Как запустить

```bash
unzip abcentrum-redesign-map-update.zip
cd abcentrum-redesign-map-update
python3 -m http.server 8000
```

Открыть:

```text
http://localhost:8000/index.html
```

## Что проверить вручную

- Отображение iframe-карты зависит от доступности OpenStreetMap в браузере пользователя.
- Кнопки `Проложить маршрут` открывают Google Maps в новой вкладке.
- На мобильных устройствах отметки карты работают как ссылки на маршрут.


## Palette hotfix

- Полностью убран прежний яркий синий акцент из CSS и HTML-классов.
- Секции, кнопки, инпуты, карта, пины и прогресс-бар переведены на палитру из загруженного Next/HTML-файла: `#0f1a2a`, `#080a0f`, `#f3f5f7`, `#ffffff`.

## Update — Yandex map

- Раздел карты переведён с Google/OpenStreetMap на Яндекс.Карты.
- Для карты используется `https://yandex.ru/map-widget/v1/` с тремя точками в параметре `pt`.
- Координаты зафиксированы строго в формате Яндекс.Карт: `longitude,latitude` для отметок и `latitude,longitude` для маршрутов.
- Кнопки «Проложить маршрут» теперь открывают построение маршрута в Яндекс.Картах через `rtext`.
- Добавлены премиальные overlay-бейджи, нумерация объектов и карточки с координатами.
- Удалены ссылки и embed на Google Maps / OpenStreetMap из кода проекта.
